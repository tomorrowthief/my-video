# 3D 神经网络能量流动图 — 设计

2026-10-12

## 目标

一个 8 秒无缝循环的氛围视觉：能量从输入层注入，沿边流向输出层，逐层点亮，输出层绽放后消散。无旁白，用途是片头、背景、封面。

## 范围判断

不进 `src/videos.ts` 的 `VIDEOS` 注册表。该表的 `defineVideo` 强制要求 narration JSON + timing + 音频目录三件套，而本场景没有旁白；套进去需要伪造一份假 timing。因此作为独立 `Composition` 直接注册在 `src/Root.tsx`。

规格：240 帧 @ 30fps（8 秒），1920×1080，复用 `src/theme.ts` 的 `FPS` / `W` / `H` / `COLORS`。

## 技术路径

手写透视投影，零新运行时依赖。不引入 three.js —— 本画面本质是"发光的点和线"，透视投影足以表达，且逐帧确定性渲染无需配置 WebGL renderer。

### 几何

5 层，节点数 `[5, 8, 8, 6, 3]`，共 30 个节点。层沿 z 轴（屏幕纵深）排开。每层内部节点排在一个**竖向椭圆环**上（`ry ≈ 1.5·rx`），带确定性径向抖动。

选椭圆环而非方格或竖列：方格在斜视角下糊成一片；竖列只是带透视的 2D 教科书图，立体感出不来；椭圆环叠成"隧道"，边自然构成可见的 3D 网格，同时竖向拉伸让它仍读得出"一层一层的节点"。

### 边

全连接 170 条视觉上是一团麻。给每条边一个种子哈希权重，权重 > 0.42 的保留（约 99 条），权重映射到线宽与不透明度。结果像一张训练好的稀疏网络，比全连接可读，也更贴近真实对象。

### 相机

不做 360° 环绕 —— 会有一半时间在看侧面薄片。方位角按 `sin(2πt)·38°` 摆动，俯仰角叠 `sin(4πt)·8°`。两者周期（1 和 1/2）都整除循环长度，无缝由构造保证。

### 立体感

五个叠加线索：

| 线索 | 做法 |
|---|---|
| 透视 | `scale = FOCAL / (z + DIST)` |
| 遮挡 | 所有可绘制物按深度排序，背到前绘制 |
| 空气透视 | 远处降低不透明度、朝背景色褪 |
| 景深 | 按深度切 3 个连续带，每带一个 `<g>` 加 blur |
| 尺寸 | 节点半径乘透视系数 |

景深用 3 个滤镜而非每元素一个：170 个 SVG 滤镜渲染跑不动。带必须在深度上连续，否则跨带的画家序会错。

### 绘制基底

全部画在一个 SVG 里。边、能量点、节点共用同一个按深度排序的绘制列表。如果节点用 div + `box-shadow`、边用 SVG，就是两个独立层叠上下文，节点会永远盖在边上面，遮挡线索当场失效。

节点辉光用「淡外圈 + 亮核心」两层圆叠出，不用 SVG 滤镜 —— 快，且逐帧确定。

## 能量节奏

一次循环是一次呼吸，不是连续的脉冲雨。归一化时间 `t = frame / 240`：

| t | 发生什么 |
|---|---|
| 0.00–0.10 | 注入：输入层充能 |
| 0.08–0.60 | 波前穿过 4 个间隙，能量点沿边飞行，节点逐层点亮 |
| 0.56–0.78 | 输出层绽放，暖色辉光峰值 |
| 0.74–1.00 | 消散，衰减到恰好 0 |

## 无缝循环

无缝由构造保证，不靠调参。所有视觉量都写成周期为 1 的 t 的函数。

**值要接上，斜率也要接上。** 衰减尾部缓出到零斜率、注入缓入从零斜率，使 t=1→0 为 C¹ 连续。只对齐值会导致每 8 秒一次肉眼可见的"咔哒"——值连续但速度突变，是这类循环最常见的翻车点。

**不能有死拍。** t≈0.95–0.05 之间呼吸是空的，因此叠一层常驻微光 `0.18 + 0.07·sin(2πt + φ)`，每节点 `φ` 不同，周期仍为 1，永不为零。加上相机全程在动，无静止瞬间。

## 确定性

节点到达时刻、边权重、每节点的相位 `φ`，全部来自种子哈希，模块加载时算一次。渲染路径中禁止 `Math.random()` —— 否则每帧是一张不同的网络，导出结果会是闪烁的雪花。这是硬约束。

层内节点到达时刻带 ±0.03 抖动：整层齐步亮起是这类图看起来廉价的首要原因。

能量点亮度与大小绑定到所在边的权重，弱边不发光。让画面说出"权重决定能量流多少"，而非纯装饰。

## 配色

复用 `src/theme.ts`：结构用 `accent` 靛蓝（极低透明度），飞行能量用 `accent2` 青绿到白热核心，输出绽放换 `warn` 琥珀暖色 —— 冷场中的一点暖，给"能量抵达"一个落点。

## 文件拆分

时间、空间、绘制三件事分开，各自可独立读懂：

```
src/nn/projection.ts   3D→2D 透视、旋转、深度分带 — 纯函数
src/nn/network.ts      确定性生成节点/边/权重 — 纯函数
src/nn/flow.ts         t → 能量状态（波前、节点亮度、边上的点）— 纯函数
src/nn/NNEnergy.tsx    投影、排序、画 SVG
src/Root.tsx           注册 composition
```

## 验证

工程无测试框架，为一个氛围循环装一套不划算。

- 静态检查：`npm run lint`（`eslint src && tsc`）
- 无缝性：导出第 0 帧与第 240 帧，应像素级一致
- 视觉：由用户在 Studio 中确认
