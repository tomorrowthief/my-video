# 电驱实验室样片

预览：http://localhost:3210/MotorAnatomy

启动：`npm run dev -- --no-open --port=3210`。

20 秒、1920×1080、30 fps，独立注册在 Studio 的 Anatomy 文件夹。
0–4 秒展开保护盖，4–10 秒演示驱动，10–17 秒演示再生制动，17–20 秒总结。
当前为无配音的文字讲解样片，尚未插入汽车正片或网页目录。

所有运动由 Remotion 当前帧计算，可直接跳帧。回收时转子仍沿原方向转动并减速。
机械尺寸、运动速度均为教学示意，不提供实测转速、功率或效率；侧栏为部件清单，底部能量链为系统关系，实验台没有绘制完整汽车传动系统。

几何工具来自 anatomy 技能的 iso-kit.ts，保留在 kit/ 下，MIT 授权见 kit/LICENSE。
本样片已做 TypeScript、组件 lint 和 Studio 关键帧目视检查，未运行 anatomy 的完整几何审计，也未导出 MP4。

## 神经元计算实验台

预览：http://localhost:3210/NeuronAnatomy

30 秒、1920×1080、30 fps；独立的无配音文字讲解。
五个步骤：输入、乘权重、加偏置求和、ReLU 激活、调整第一个权重。
输入为 0.8 和 0.4，初始权重为 0.5 和 -0.75，偏置 -0.2；z=-0.1，输出为 0。
21–26 秒将第一个权重平滑调到 1，z 与输出最终均为 0.3。
这不是训练演示，不包含损失函数或反向传播。光点表示计算进度，不代表电流。
已检查全部 900 帧的计算恒等式与输出单调性，检查关键帧预览、TypeScript 与组件 lint；未执行完整 anatomy 几何审计。
